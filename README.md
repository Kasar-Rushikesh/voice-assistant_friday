

# Voice Assistant "FRIDAY" Using Python 🎙️🤖

FRIDAY is a Python-based **voice assistant** inspired by virtual assistants like Alexa and Google Assistant.  
It listens to voice commands, processes them using speech recognition, and performs various tasks such as opening applications, searching the web, and responding with speech.

---

## 🚀 Features
- Voice command recognition
- Text-to-speech responses
- Opens websites & applications
- Tells date and time
- Searches Google & Wikipedia
- Simple and extensible design

---

## 🛠️ Technologies Used
- Python
- SpeechRecognition
- Pyttsx3
- PyAudio
- Wikipedia API
- OS & Webbrowser modules
